# commit 規約

Source:
Language: 日本語

## 件名
- 形式：`<type>: <要約>`（Conventional Commits）
- type：`feat`（機能追加）・`fix`（バグ修正）・`docs`（ドキュメント）・`refactor`（振る舞いを変えない改修）・`test`（テスト）・`chore`（ビルド・設定・雑務）
- 要約は日本語で、何を変えたかを簡潔に書く。末尾に句点を付けない。

## 本文
- 必要なときだけ書く。件名との間は 1 行空ける。
- 何を変えたかより、なぜ変えたかを書く。
- 関連する issue があれば `Closes #<番号>` などで示す。
