# プロジェクト概要

## サービスの目的
仕事・リアルの友人・ゲーム・推し活など、場面ごとに別々のチャットアプリを入れたり、アカウントを作り分けたりしている人向けの、リアルタイムチャットアプリ。
1 つのアカウントで複数のプロフィールを作り、サーバーや友人ごとにどのプロフィールを使うかを設定できるようにする。これにより、1 つのアプリで場面を切り替えずにやり取りできるようにする。

## 主要なドメイン概念
- **アカウント**：ログインの単位。1 人に 1 つ。
- **プロフィール**：アカウントの下に複数作れる「顔」。avatar・name・bio を持つ。アカウントごとにデフォルトプロフィールを 1 つ持つ。
- **サーバー**：Discord のようなコミュニティの単位。中にチャンネルを持つ。参加するときに、そのサーバーで使うプロフィールを選ぶ（未設定ならデフォルトプロフィール）。
- **チャンネル**：サーバーの中の会話の場。
- **フレンド**：アカウント同士の関係。各自が相手ごとに、見せるプロフィールを選べる（未設定ならデフォルトプロフィール）。相手からは、自分に割り当てられたプロフィールしか見えない。同じ人が別のプロフィールを持っていることも分からない。
- **DM**：フレンドとの 1 対 1 の会話。そのフレンドに割り当てたプロフィールを使う。
- **グループ DM**：少人数の会話。グループ DM ごとに使うプロフィールを選ぶ（未設定ならデフォルトプロフィール）。
- **メッセージ**：チャンネル・DM・グループ DM に投稿するもの。リアルタイムに届く。

## アーキテクチャ／ディレクトリ構成
pnpm workspaces の monorepo。クライアントは Web のみ。

- `apps/web/` — Next.js。画面。
- `apps/server/` — Hono。REST API と WebSocket（リアルタイム配信）。常駐するサーバーとして動かす（サーバーレス環境では WebSocket の接続を保てないため、Next.js とは分ける）。
- `packages/db/` — Drizzle のスキーマ・マイグレーション。
- `packages/shared/` — web と server で共有する型・バリデーション。

## 技術スタック
- 言語：TypeScript
- フロントエンド：Next.js
- バックエンド：Hono（Node.js）
- リアルタイム通信：WebSocket
- DB：Neon（Postgres）＋ Drizzle ORM
- 認証：Auth.js
- パッケージマネージャ：pnpm
