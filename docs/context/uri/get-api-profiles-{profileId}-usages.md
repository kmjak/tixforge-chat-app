# `GET /api/profiles/{profileId}/usages`
## プロフィールの使用先

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000008） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | 自分のプロフィールだけを扱う |
| パスパラメータ | 下の表 |
| リクエスト | なし |
| query | なし |
| 呼び出し元 URL | [`/profiles/{profileId}`](../routes/profiles-{profileId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `profileId` | string | プロフィールの id（UUID）。自分のプロフィールでない・存在しない・UUID の形でないときは 404 |

そのプロフィールを割り当てている場（[schema.md の「プロフィールの割り当て」](../schema.md#プロフィールの割り当て)）の一覧。割り当ての場はそれぞれのチケットで足す（GT-000008 の時点では、割り当ての場が無いので常に空）。

### http status
#### 200 使用先

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `usages` | `Usage[]` | はい | 使用先。無ければ空の配列 |

`Usage`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `type` | `"server" \| "friend" \| "groupDm"` | はい | 割り当ての場の種類 |
| `id` | string | はい | 割り当て先（サーバーなど）の id |
| `name` | string | はい | 割り当て先の表示名（サーバーの名前など） |

```json
{ "usages": [] }
```

#### 404 自分のプロフィールでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。他人のプロフィールでも 403 にはせず 404 にする（その id のプロフィールが存在するかを知らせない）。
