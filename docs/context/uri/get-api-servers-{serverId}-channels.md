# `GET /api/servers/{serverId}/channels`
## チャンネルの一覧

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000011） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | そのサーバーのメンバーであること |
| パスパラメータ | 下の表 |
| リクエスト | なし |
| query | なし |
| ページネーション | なし（カテゴリに属さないチャンネルは 10 個まで） |
| 呼び出し元 URL | [`/servers/{serverId}`](../routes/servers-{serverId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `serverId` | string | サーバーの id（UUID） |

削除したチャンネルは含めない。並び順は作った順（`position`、同じなら `created_at`）。

### http status
#### 200 一覧

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `channels` | `Channel[]` | はい | チャンネル |

`Channel`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `id` | string | はい | チャンネルの id（UUID） |
| `name` | string | はい | チャンネル名 |
| `isDefault` | boolean | はい | 既定のチャンネル（`一般`）か |

```json
{ "channels": [
  { "id": "3f1a…", "name": "一般", "isDefault": true },
  { "id": "8c2b…", "name": "雑談", "isDefault": false }
] }
```

#### 404 メンバーでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。メンバーでなければ、サーバーやチャンネルが存在しても 404 にする（[schema.md の「参加者の確認」](../schema.md#参加者の確認)）。削除したチャンネルも 404。
