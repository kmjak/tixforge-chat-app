# `GET /health`
## ヘルスチェック

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000002） |
| メソッド | GET |
| 認証が必要か | 不要 |
| 権限 | なし |
| パスパラメータ | なし |
| リクエスト | なし |
| query | なし |
| 呼び出し元 URL | なし（監視・開発時の確認に使う。画面からは呼ばない） |

server が動いていて DB に接続できるかを返す。DB に `SELECT 1` を実行して確かめる。

### http status
#### 200 DB に接続できる

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `status` | `"ok"` | はい | server の状態 |
| `db` | `"ok"` | はい | DB の状態 |

```json
{ "status": "ok", "db": "ok" }
```

#### 503 DB に接続できない・`DATABASE_URL` が無い
**エラーの共通形式の例外**：監視のため、200 と同じ形で DB の状態を返す。

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `status` | `"error"` | はい | server の状態 |
| `db` | `"error"` | はい | DB の状態 |

```json
{ "status": "error", "db": "error" }
```
