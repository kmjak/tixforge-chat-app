# `GET /api/profiles`
## 自分のプロフィールの一覧

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000008） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | 自分のプロフィールだけを扱う |
| パスパラメータ | なし |
| リクエスト | なし |
| query | なし |
| ページネーション | なし（1 つのアカウントは 5 個まで） |
| 呼び出し元 URL | [`/profiles`](../routes/profiles.md) |

### http status
#### 200 一覧

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `profiles` | `Profile[]` | はい | 自分のプロフィール。デフォルトが先頭、残りは作った順 |

`Profile`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `id` | string | はい | プロフィールの id（UUID） |
| `name` | string | はい | 名前（1〜32 文字） |
| `bio` | string | はい | 自己紹介（0〜190 文字。空文字のこともある） |
| `isDefault` | boolean | はい | デフォルトのプロフィールか |

```json
{ "profiles": [
  { "id": "0b6f1c4e-8a0e-4c39-9f53-2f3f1f0e7a10", "name": "Taro", "bio": "", "isDefault": true },
  { "id": "5d2a9b7c-1e4f-4a8b-b3c2-7e6d5f4a3b21", "name": "ゲーム用", "bio": "", "isDefault": false }
] }
```
