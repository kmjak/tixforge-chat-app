# `POST /api/servers`
## サーバーの作成

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | POST |
| 認証が必要か | 必要 |
| 権限 | ログインしていること |
| パスパラメータ | なし |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/servers`](../routes/servers.md) |

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `name` | string | はい | サーバー名。前後の空白を除いて 1〜100 文字。除いた値で保存する |
| `profileId` | string | はい | このサーバーで使う自分のプロフィールの id |

作った人がオーナーになり、選んだプロフィールでメンバーとして参加した状態になる。既定のチャンネル `一般` は GT-000011 から作る。

### http status
#### 201 作った

`Server`（[`GET /api/servers`](get-api-servers.md) と同じ形。`isOwner` は `true`）

#### 400 入力が正しくない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：

| code | 起きるとき |
|------|-----------|
| `INVALID_SERVER_NAME` | `name` が文字列でない、または前後の空白を除いて 1〜100 文字でない |
| `INVALID_PROFILE` | `profileId` が文字列でない・自分のプロフィールでない |
| `BAD_REQUEST` | 本文が JSON のオブジェクトでない |
