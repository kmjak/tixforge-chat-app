# `POST /api/invites/{token}/join`
## 招待での参加

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | POST |
| 認証が必要か | 必要 |
| 権限 | ログインしていること（招待リンクを知っていること） |
| パスパラメータ | 下の表 |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/invites/{token}`](../routes/invites-{token}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `token` | string | 招待リンクのトークン |

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `profileId` | string | はい | このサーバーで使う自分のプロフィールの id |

既にメンバーなら、二重に参加せず、使うプロフィールも変えずに `alreadyMember: true` を返す。

### http status
#### 200 参加した（または既にメンバー）

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `serverId` | string | はい | 参加したサーバーの id |
| `alreadyMember` | boolean | はい | 既にメンバーだったか |

```json
{ "serverId": "7c1e…", "alreadyMember": false }
```

#### 400 自分のプロフィールでない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVALID_PROFILE`（`profileId` が文字列でない・自分のプロフィールでない）

#### 404 招待リンクが存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVITE_NOT_FOUND`

#### 410 招待リンクの有効期限が切れている
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVITE_EXPIRED`
