# `PATCH /api/servers/{serverId}/members/me`
## このサーバーで使うプロフィールの変更

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | PATCH |
| 認証が必要か | 必要 |
| 権限 | そのサーバーのメンバーであること |
| パスパラメータ | 下の表 |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/servers/{serverId}`](../routes/servers-{serverId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `serverId` | string | サーバーの id（UUID）。自分がメンバーでない・存在しない・UUID の形でないときは 404 |

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `profileId` | string | はい | このサーバーで使う自分のプロフィールの id |

### http status
#### 200 変えた後のサーバー

`Server`（[`GET /api/servers`](get-api-servers.md) と同じ形）

#### 400 自分のプロフィールでない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVALID_PROFILE`（`profileId` が文字列でない・自分のプロフィールでない）

#### 404 メンバーでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。メンバーでなければ、サーバーが存在しても 404 にする（[schema.md の「参加者の確認」](../schema.md#参加者の確認)）。
