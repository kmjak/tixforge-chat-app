# `PATCH /api/profiles/{profileId}`
## プロフィールの編集・デフォルトへの切り替え

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000008） |
| メソッド | PATCH |
| 認証が必要か | 必要 |
| 権限 | 自分のプロフィールだけを扱う |
| パスパラメータ | 下の表 |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/profiles/{profileId}`](../routes/profiles-{profileId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `profileId` | string | プロフィールの id（UUID）。自分のプロフィールでない・存在しない・UUID の形でないときは 404 |

### リクエスト
どれも省略できる。送った項目だけを変える。

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `name` | string | いいえ | 名前。前後の空白を除いて 1〜32 文字。除いた値で保存する |
| `bio` | string | いいえ | 自己紹介。0〜190 文字（入力のまま保存する） |
| `isDefault` | `true` | いいえ | `true` にすると、このプロフィールをデフォルトにし、今までのデフォルトはデフォルトでなくなる（デフォルトは常に 1 つ）。`false` は受け付けない（デフォルトを外すと 0 個になるため。別のプロフィールを `true` にする） |

```json
{ "name": "ゲーム用", "bio": "週末だけ", "isDefault": true }
```

### http status
#### 200 変えた後のプロフィール

`Profile`（[`GET /api/profiles`](get-api-profiles.md) と同じ形）

#### 400 入力が正しくない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：

| code | 起きるとき |
|------|-----------|
| `INVALID_NAME` | `name` が文字列でない、または前後の空白を除いて 1〜32 文字でない |
| `INVALID_BIO` | `bio` が文字列でない、または 190 文字より長い |
| `BAD_REQUEST` | 本文が JSON のオブジェクトでない |

`isDefault` が `true` 以外のときも `BAD_REQUEST`。

#### 404 自分のプロフィールでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。他人のプロフィールでも 403 にはせず 404 にする（その id のプロフィールが存在するかを知らせない）。
