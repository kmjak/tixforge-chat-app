# `GET /api/servers/{serverId}/members`
## メンバーの一覧

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | そのサーバーのメンバーであること |
| パスパラメータ | 下の表 |
| リクエスト | なし |
| query | なし |
| ページネーション | なし |
| 呼び出し元 URL | [`/servers/{serverId}`](../routes/servers-{serverId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `serverId` | string | サーバーの id（UUID）。自分がメンバーでない・存在しない・UUID の形でないときは 404 |

各メンバーは、そのサーバーで選んだプロフィールで返す。アカウントの id・メールアドレス・その人のほかのプロフィールは含めない（[schema.md の「相手に見せてよいもの・見せてはいけないもの」](../schema.md#相手に見せてよいもの見せてはいけないもの)）。見る人がフレンドのメンバーをフレンドの割り当てで返す「フレンドが優先」は GT-000015 で足す。

### http status
#### 200 メンバー

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `members` | `Member[]` | はい | メンバー（参加した順） |

`Member`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `profile` | `{ id: string, name: string, bio: string }` | はい | そのメンバーを見る人に見せるプロフィール |
| `isOwner` | boolean | はい | オーナーか |
| `isMe` | boolean | はい | 自分か |

```json
{ "members": [
  { "profile": { "id": "5d2a…", "name": "ゲーム用", "bio": "" }, "isOwner": true, "isMe": true },
  { "profile": { "id": "9b3f…", "name": "Hanako", "bio": "よろしく" }, "isOwner": false, "isMe": false }
] }
```

#### 404 メンバーでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。メンバーでなければ、サーバーが存在しても 404 にする（[schema.md の「参加者の確認」](../schema.md#参加者の確認)）。
