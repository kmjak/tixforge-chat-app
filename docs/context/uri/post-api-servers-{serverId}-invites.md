# `POST /api/servers/{serverId}/invites`
## 招待リンクの作成

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | POST |
| 認証が必要か | 必要 |
| 権限 | そのサーバーのメンバーであること（メンバーなら誰でも作れる） |
| パスパラメータ | 下の表 |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/servers/{serverId}`](../routes/servers-{serverId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `serverId` | string | サーバーの id（UUID）。自分がメンバーでない・存在しない・UUID の形でないときは 404 |

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `expiresInHours` | `1 \| 6 \| 12 \| 24 \| 48 \| null` | はい | 有効期限（作ってからの時間）。`null` は無制限 |

使える回数に上限は無い。MVP では取り消し・削除をしない。招待の画面の URL は web の [`/invites/{token}`](../routes/invites-{token}.md)。

### http status
#### 201 作った

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `token` | string | はい | 推測できないランダムなトークン（暗号論的な乱数 32 バイトの base64url） |
| `expiresAt` | `string \| null` | はい | 有効期限（ISO 8601）。無制限なら `null` |

```json
{ "token": "q3Zx…", "expiresAt": "2026-10-20T09:00:00.000Z" }
```

#### 400 入力が正しくない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVALID_EXPIRY`（`expiresInHours` が選択肢のどれでもない）

#### 404 メンバーでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。メンバーでなければ、サーバーが存在しても 404 にする（[schema.md の「参加者の確認」](../schema.md#参加者の確認)）。
