# `GET /api/servers`
## 自分が参加しているサーバーの一覧

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000009） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | ログインしていること（自分がメンバーのサーバーだけ） |
| パスパラメータ | なし |
| リクエスト | なし |
| query | なし |
| ページネーション | なし |
| 呼び出し元 URL | [`/servers`](../routes/servers.md) |

### http status
#### 200 一覧

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `servers` | `Server[]` | はい | 参加しているサーバー（参加した順） |

`Server`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `id` | string | はい | サーバーの id（UUID） |
| `name` | string | はい | サーバー名（1〜100 文字） |
| `isOwner` | boolean | はい | 自分がオーナーか |
| `myProfile` | `{ id: string, name: string }` | はい | そのサーバーで自分が使うプロフィール |

```json
{ "servers": [{ "id": "7c1e…", "name": "ゲーム仲間", "isOwner": true, "myProfile": { "id": "5d2a…", "name": "ゲーム用" } }] }
```
