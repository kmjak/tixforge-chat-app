# `POST /api/servers/{serverId}/channels`
## チャンネルの作成

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000011） |
| メソッド | POST |
| 認証が必要か | 必要 |
| 権限 | そのサーバーのオーナーであること |
| パスパラメータ | 下の表 |
| リクエスト | 下の表（JSON） |
| query | なし |
| 呼び出し元 URL | [`/servers/{serverId}`](../routes/servers-{serverId}.md) |

### パスパラメータ

| フィールド | 型 | 説明 |
|------------|----|------|
| `serverId` | string | サーバーの id（UUID） |

### リクエスト

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `name` | string | はい | チャンネル名。前後の空白を除いて 1〜100 文字で、文字（あらゆる言語。結合文字を含む）・数字・`-`・`_` だけ。スペース・記号・絵文字は使えない。除いた値で保存する。同じサーバーの中で重複してもよい |

カテゴリに属さないチャンネルは、1 つのサーバーに既定のチャンネルを含めて 10 個まで（削除したものは数えない）。

### http status
#### 201 作った

`Channel`（[`GET /api/servers/{serverId}/channels`](get-api-servers-{serverId}-channels.md) と同じ形。`isDefault` は `false`）

#### 400 名前が規則に合わない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`INVALID_CHANNEL_NAME`（ほかに、本文が JSON のオブジェクトでなければ `BAD_REQUEST`）

#### 403 オーナーでない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_SERVER_OWNER`（メンバーだがオーナーでない。メンバーにはサーバーとチャンネルが見えているので、存在を隠さずに理由を返す）

#### 404 メンバーでない・存在しない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`NOT_FOUND`。メンバーでなければ、サーバーやチャンネルが存在しても 404 にする（[schema.md の「参加者の確認」](../schema.md#参加者の確認)）。削除したチャンネルも 404。

#### 409 チャンネルの数が上限
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`CHANNEL_LIMIT_REACHED`
