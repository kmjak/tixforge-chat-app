# `GET /api/me`
## ログイン中のアカウント

| 項目 | 内容 |
|------|------|
| 状態 | 実装済み（GT-000007） |
| メソッド | GET |
| 認証が必要か | 必要 |
| 権限 | ログインしていること（ほかの条件はなし） |
| パスパラメータ | なし |
| リクエスト | なし |
| query | なし |
| 呼び出し元 URL | なし（画面からはまだ呼ばない。ログイン確認の動作の確認と、後の画面で使う） |

呼び出したアカウント（本人）の情報を返す。本人には、アカウントの id とメールアドレスを見せてよい（[schema.md の「相手に見せてよいもの・見せてはいけないもの」](../schema.md#相手に見せてよいもの見せてはいけないもの)）。

### http status
#### 200 ログインしている

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `id` | string | はい | アカウントの id（UUID。ほかのアカウントには見せない） |
| `email` | string | はい | メールアドレス |
| `defaultProfile` | `Profile` | はい | デフォルトのプロフィール（下の表） |

`Profile`

| フィールド | 型 | 必須 | 説明 |
|------------|----|------|------|
| `id` | string | はい | プロフィールの id（UUID） |
| `name` | string | はい | 名前（1〜32 文字） |
| `bio` | string | はい | 自己紹介（0〜190 文字。空文字のこともある） |

```json
{
  "id": "0b6f1c4e-8a0e-4c39-9f53-2f3f1f0e7a10",
  "email": "taro@example.com",
  "defaultProfile": {
    "id": "5d2a9b7c-1e4f-4a8b-b3c2-7e6d5f4a3b21",
    "name": "Taro",
    "bio": ""
  }
}
```

#### 401 ログインしていない
[エラーの共通形式](../uri.md#エラーの共通形式)。`code`：`UNAUTHORIZED`（セッションが無い・無効・サインアウト済み・期限切れ）

```json
{ "code": "UNAUTHORIZED", "message": "Unauthorized" }
```
